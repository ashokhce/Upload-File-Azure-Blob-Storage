## Meeting Overview
This meeting was a demonstration of a new claims audit platform designed to streamline the quality assurance and audit process for claims operations. The presentation was led by Jeanette Lamour, who showcased the platform's features and capabilities.

---

## Key Discussion Points

### 1. Platform Homepage and Overview (0:00 - 0:31)
**Presenter: Jeanette Lamour**

- The new platform serves as the central hub for starting audits
- Homepage features include:
  - Overview of current month's scores
  - Number of reviews completed
  - Dashboard with key metrics

### 2. Major Efficiency Improvements (0:31 - 1:06)
**Key Benefits:**

- **Current Process (Pain Point):**
  - Manager must manually access each client's dashboard
  - Manager must pull reports for each client
  - Manager must identify claim files requiring review each month
  - This creates delays and bottlenecks

- **New Automated Process:**
  - Leah has implemented an automated pipeline
  - Pipeline runs on the 1st of every month
  - Automatically pulls all applicable files needing review
  - Team can begin reviews immediately on day one
  - Eliminates the entire manual file retrieval process

### 3. Review Workflow Demonstration (1:06 - 1:24)
**Process Steps:**

1. Click on a file to initiate review
2. View claim overview information
3. Create a new review
4. Select applicable phases for the specific claim
5. Note: Not all files require every phase to be reviewed

### 4. Platform Flexibility and Self-Service Capabilities (1:24 - 2:08)
**Key Feature Highlighted:**

- **User Empowerment:**
  - Jeanette demonstrated the ability to modify the platform directly
  - Example: Last week, phases were out of order
  - She was able to add a column to the existing table
  - Reordered phases to match the actual review sequence
  - All changes were made without IT department involvement
  - No need to submit IT tickets or wait for unknown completion timelines

**Significance:** This represents a major shift from traditional IT-dependent processes to user-driven modifications, enabling faster iteration and improvements.

### 7. Flexibility for New Employee Training (41:36 - 42:24)
**Discussed by: John Crawford and Ashok Kumar**

- **Question Addressed:** Can the system handle increased review frequency for new employees?

- **Answer:**
  - **Manager Level:** Managers can absolutely configure more frequent reviews for new handlers
  - **QA Team Level (Closed Files):**
    - Focus is on overall operational health
    - Randomization is prioritized to maintain unbiased sampling
    - Different approach than manager-level reviews
  
- **Use Case:** New adjusters typically receive more scrutiny until they're fully trained

## Appendix: Key Terminology
- **QA:** Quality Assurance
- **Claims Audit:** Process of reviewing insurance claims for accuracy and compliance
- **Handler/Adjuster:** Insurance professional who manages claims
- **Phases:** Different stages of claim review (e.g., initial review, documentation check, final approval)
- **Pipeline:** Automated data processing workflow
